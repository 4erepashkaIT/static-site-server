About me

I'm a final-year Applied Computer Science student at SUAI (Russia), graduating in spring 2026. I've tried frontend, Android, Unity and QA, and the part I enjoyed most was always the infrastructure underneath: servers, networks, and the things that keep an application running.

So I chose the infrastructure track. My plan is to start as a Linux system administrator or technical support engineer and grow into DevOps / SRE. I learn by doing: I rent my own VPS running Ubuntu 24.04, follow the roadmap.sh DevOps roadmap, and keep notes and an incident log for everything that breaks.

Projects

Each one is a project from roadmap.sh, built and running on my own server.

  1. SSH Remote Server Setup

    Set up a VPS with key-only SSH access: my own sudo user instead of root, password login and root login disabled through an sshd_config.d drop-in, host aliases in ~/.ssh/config, and fail2ban protecting SSH.

    Repository Task on roadmap.sh

  2. Server Performance Stats

    A Bash script that reports CPU, memory and disk usage, load average, uptime and the top processes by CPU and memory. Written with functions, awk and vmstat; deployed to the server with Git.

    Repository Task on roadmap.sh

  3. Log Archive Tool

    A CLI tool that compresses a log directory into a timestamped tar.gz, verifies the archive by restoring it, deletes old archives and runs on a schedule with a systemd timer.

    Repository Task on roadmap.sh

  4. Static Site Server you are here

    This website. Static HTML and CSS served by nginx on my VPS, deployed from my laptop with a single rsync script.

    Repository Task on roadmap.sh
